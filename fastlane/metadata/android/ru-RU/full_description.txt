Kairos расставляет ваши задачи в порядке выполнения и вписывает их в промежутки дня, на подходящее время.

<b>Порядок, который можно объяснить</b>
Каждой задаче присваивается рейтинг приоритета (WSJF): ее ценность (приоритет P0, P1 или P2 плюс срочность срока) делится на трудоемкость в баллах. Небольшое и важное идет раньше крупного и далекого; просроченная задача всегда первая. «Почему это место?» показывает расчет одним касанием.

<b>Реалистичный день</b>
<ul>
<li>Задачи размещаются вокруг ваших встреч, после каждой из них оставляется запас времени.</li>
<li>Интервалы deep work защищены; во второй половине дня сложные задачи уступают место более легким.</li>
<li>Фиксированное время, повторяющиеся задачи (ежедневно, по будням, еженедельно, «23-го числа каждого месяца»), зависимости между задачами, редактируемые подзадачи, официальные праздники Франции.</li>
</ul>

<b>Быстрая запись без усилий (GTD)</b>
Идея? Заметка. Задача? Достаточно названия: она ждет в разделе «К обработке», пока вы не укажете приоритет и размер, по одному касанию на каждый.

<b>Реальное время</b>
Таймер для каждой задачи с постоянным уведомлением; сигналы, когда вы превысили оценку, забыли запущенный таймер или пора отдохнуть, даже при закрытом приложении. Статистика сравнивает ваши оценки с фактически затраченным временем.

<b>Управление командой (по желанию)</b>
По умолчанию выключено: управление командой добавляет второе пространство для manager, который остается единственным пользователем:
<ul>
<li>Участники и отсутствия, общий бэклог, ход работ с журналом.</li>
<li>Загрузка каждого человека относительно его вместимости и предложенное распределение задач; ваши личные задачи могут учитываться в вашей загрузке.</li>
<li>Прогнозы Monte Carlo: даты завершения в виде вероятности в процентах, под угрозой сроки, сценарии «Что если…?».</li>
<li>Обмен файлами с участниками, которые пользуются Kairos: они получают свои задачи и присылают обратно свой прогресс.</li>
<li>Все остается на устройстве; личное пространство никогда не показывает ничего из команды.</li>
</ul>

<b>Ваши данные остаются у вас</b>
<ul>
<li>Без аккаунта, без рекламы, без трекеров, без разрешения на доступ к сети.</li>
<li>Экспорт и импорт файла JSON для резервной копии или смены устройства; либо актуальная копия в синхронизируемой папке.</li>
<li>Встречи из файла календаря (.ics: Outlook, Google, Thunderbird) или, по желанию, из календарей вашего телефона: тогда Kairos запросит доступ к календарю только для чтения и по-прежнему никогда не подключается к сети.</li>
</ul>

Kairos также доступен для Windows, Linux и macOS и в браузере. Свободное программное обеспечение под лицензией MIT на английском, французском, испанском, немецком, русском и итальянском языках (выбор в настройках; по умолчанию язык вашей системы, если он из этого списка, иначе английский).
